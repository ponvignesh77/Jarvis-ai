# JARVIS AI 3.5

A futuristic AI assistant dashboard with voice input, chat, an animated gold particle core, and English and Tamil support.

## Features
- Voice input (speech recognition) and spoken replies (text-to-speech)
- Animated particle sphere with pinch, scroll, and double-tap zoom
- One-by-one app reveal with quick-action cards
- English and Tamil interface
- Light and dark themes

## Run Locally
Open `index.html` in any modern browser (Chrome, Edge, or Safari recommended for voice).

## Live Demo
After enabling GitHub Pages, your site is at:
`https://YOUR-USERNAME.github.io/jarvis-ai-3.5/`

## Notes
- This web version is a preview. Replies come from built-in demo logic.
- Phone control (opening apps, changing settings) works only in the Android app.
- Never commit API keys. Use a backend or `.env` file for private credentials.
